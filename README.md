# location-platform-an-overview-for-developers-dtseu-2026

A repository for the code that was shown during the "ArcGIS Location Platform:
An Overview for Developers" technical session.

ArcGIS Location Platform is a geospatial platform as a service (PaaS) for
developers who are looking to integrate location capabilities into their apps,
business systems, and products. It enables developers to create apps and extend
ArcGIS functionality using ArcGIS APIs, SDKs and tools. In this technical
session, speakers discuss what's new and what's different between ArcGIS
Location Platform and ArcGIS Online or ArcGIS Enterprise when developing apps
and how your organization might benefit from it.

Tuesday, 20 Oct | 16:00 - 17:00 CEST | (15:00 - 16:00 BST) | Conclusio 1——Level
C2 | Congress Center

## Slides and recording

Most of the slides are made available at [Esri Events > Proceedings](https://www.esri.com/en-us/about/events/index/proceedings).

## Running the demos

To run the demos, add a new file `config.js` at the root of the repo that contains a token. The contents of the file should be

```js
const API_KEY = "INSERT_API_KEY"; // token with required privileges
```
